# customer_behavior_analysis
This repository presents an end-to-end customer behavior analysis project focused on deriving actionable business insights from raw data. It includes data loading and EDA using Python (Pandas), business analysis with SQL, interactive Power BI dashboards, AI assisted reporting and presentation generation using Gamma AI.

🎯 **Project Objectives**
  * Perform structured data ingestion and preparation for analysis

  * Explore and understand data patterns through exploratory data analysis
  
  * Answer business-critical questions using SQL-based analysis
  
  * Visualize insights through interactive dashboards
  
  * Communicate findings via professional reports and presentations
  
  * Provide actionable business recommendations

🛠️**Tools & Technologies**

  * Python – Data ingestion and preprocessing
  
  * Pandas – Exploratory Data Analysis (EDA)
  
  * PostgreSQL – Business queries and analytical SQL
  
  * Power BI – Interactive dashboard creation
  
  * Gamma AI – AI-assisted PowerPoint creation
